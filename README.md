# Terminal Sound Alerts VS Code Extension 🔊

A VS Code extension that plays custom sounds based on terminal output events.

Get instant audio feedback when:

- ❌ An **error** occurs in the terminal
- ⚠️ A **warning** appears
- ✅ A command executes **successfully**
- 🔔 A **normal terminal output** is detected

Perfect for developers who want audio notifications while coding, running builds, or monitoring long terminal tasks.

---

## Features

### ❌ Error Sound
Plays a sound when an error occurs in the terminal.

Examples:
- Build failed
- Compilation error
- Runtime error
- Failed tests

### ⚠️ Warning Sound
Plays a warning sound when warning messages are detected.

Examples:
- Deprecation warnings
- Lint warnings
- Compiler warnings

### ✅ Success Sound
Plays a success sound when a command finishes successfully.

Examples:
- Build completed
- Tests passed
- Server started successfully
- Command exits with code `0`

### 🔔 Normal Output Sound
Plays a subtle sound for regular terminal activity/output.

Useful for:
- Long-running commands
- Background processes
- Monitoring logs
